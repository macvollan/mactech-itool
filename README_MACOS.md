# 🍎 MacTech iTool - macOS Setup Guide
**MacTech Solutions Lab** • Fully Compatible with Apple Silicon (M1/M2/M3/M4) & Intel

### Prerequisites
macOS 11.0 (Big Sur) or higher. Native Apple lockdown framework is supported out of the box.

### Quick Start
1. Open Terminal in this directory:
   ```bash
   chmod +x setup_mac.sh launch_mac.command
   ./setup_mac.sh
   ```
2. Double-click `launch_mac.command` to start MacTech iTool.

### Optional CLI Forensics
If you use Homebrew, install extended tools:
```bash
brew install libimobiledevice idevicerestore ideviceinstaller
```
